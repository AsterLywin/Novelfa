Bundled "recommended" fonts (WPF parity: B Koodak, Vazirmatn).

Drop the .ttf/.otf files here (e.g. from EpubReader/RecommendedFonts/ in the
WPF project). On first launch the app copies them into its private fonts dir
and they appear in the reader's font list automatically — no system install
needed. Files must be copied from a real machine: the MCP GitHub tools are
text-only and corrupt binaries, so they cannot be pushed through the agent.
